# 🥜 모이글

글을 쓰면 견과류(아몬드·호두·헤이즐넛·땅콩·피스타치오·캐슈넛)가 글자 모양으로 놓이고,
화면을 누르면 새들(참새·비둘기·박새·까치)이 날아와 조금씩 쪼아먹다가 결국 글 전체가 사라지는 웹사이트입니다.

## 기능

- 최대 2,000자까지 입력할 수 있고, 긴 글은 스크롤해서 볼 수 있습니다.
- 글씨 크기를 50%~200%로 조절할 수 있습니다 (화면에 맞춘 기본 크기가 100%). 공유 링크에도 글씨 크기가 함께 담깁니다.
- 휴대폰 화면에서는 전용 레이아웃으로 바뀌고, 입력 패널을 **✏️ 글쓰기 · 설정** 버튼으로 접고 펼 수 있습니다 (글을 쓰면 자동으로 접힘).
- 처음 방문하면 PC 환경을 추천하는 공지가 한 번 뜹니다 (확인하면 그 브라우저에서는 다시 뜨지 않음).
- 사이트에 처음 들어오면 화면을 한 번 누르기 전까지 새들이 오지 않습니다.
- 새가 쪼아먹는 중에 화면을 누르면 근처 새들이 놀라서 달아납니다.
- 시간 속도를 0.5배에서 8배까지 바꿀 수 있습니다.
- **원문 보기**: 📜 원문 버튼을 누르면 견과류 글씨 위에 보통 글꼴로 쓴 원래 글이 나타나고, 다시 누르면 사라집니다.
- **공유**: 쓴 글이 주소(`#t=...`) 안에 담긴 링크를 만들어 복사하거나, 지금 화면을 PNG 이미지로 저장할 수 있습니다.
  서버는 필요 없습니다. 링크를 연 사람은 같은 글이 놓인 화면에서 시작합니다.
  공유받은 화면에서는 글을 고칠 수 없고, **✍️ 나도 글 쓰러 가기** 버튼으로 원래 사이트로 갈 수 있습니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 (입력창, 공유 창 등) |
| `style.css` | 디자인 |
| `script.js` | 견과류 배치, 새 움직임, 공유 기능 |

## 로컬에서 실행

`index.html`을 브라우저로 바로 열어도 동작합니다.
VS Code에서는 **Live Server** 확장을 설치한 뒤 `index.html`에서 우클릭 → *Open with Live Server*를 쓰면 편합니다.

## GitHub Pages로 배포

1. 이 폴더의 파일들을 저장소에 올립니다 (`index.html`이 저장소 최상위에 있어야 합니다).
2. 저장소 **Settings → Pages**에서 *Source*를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 고릅니다.
3. 잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있습니다.
